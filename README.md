WorkVital – Worker Health and Safety Monitoring System

 
 Project Overview:
WorkVital is an IoT-based worker health and safety monitoring system designed to improve workplace safety by identifying harmful environmental conditions such as chemical fumes and heat exposure.

Problem Statement:
Workers in industries may be exposed to dangerous chemical fumes and high temperatures. Lack of continuous monitoring can delay emergency alerts and increase health risks.

Objectives:
- Monitor workplace environmental conditions.
- Detect harmful gases using sensors.
- Monitor temperature and surrounding conditions.
- Provide early alerts when unsafe conditions are detected.
- Improve worker health and safety.

Technologies Used:
- ESP32
- IoT
- MQTT
- Firebase
- Environmental Sensors

System Architecture:
Sensors → ESP32 → MQTT → Firebase → Dashboard → Early Alert

Applications:
- Chemical industries
- Manufacturing industries
- Metal and steel industries
- Industrial workplaces

Sustainable Development Goal
**SDG 3 – Good Health and Well-being**

WorkVital aims to support safer working environments and reduce health risks.

Future Scope:
- Real-time worker monitoring
- Mobile application integration
- Advanced environmental analysis
- Improved emergency notification system
