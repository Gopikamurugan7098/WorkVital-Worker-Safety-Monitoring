# WorkVital – Components Used

## Hardware Components

| S.No | Component | Purpose |
|---|---|---|
| 1 | ESP32 | Main controller |
| 2 | MQ-135 Gas Sensor | Detects harmful gas and air quality changes |
| 3 | Temperature Sensor | Monitors temperature |

## Communication Technologies

- MQTT
- Firebase

## Project Application

Workplace Health and Safety Monitoring.

## Sustainable Development Goal

SDG 3 – Good Health and Well-being.
